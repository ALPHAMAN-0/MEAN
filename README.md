# MEAN Stack - Learning Repository

A learning repository for the MEAN stack -- MongoDB, Express.js, Angular, and Node.js. This repository is dedicated to exploring full-stack web development using this JavaScript-based technology stack.

---

## Contents

This repository is structured for progressive learning of the MEAN stack components:

| Component | Technology | Description |
|-----------|-----------|-------------|
| **M** | MongoDB | NoSQL document database for data persistence |
| **E** | Express.js | Minimal and flexible Node.js web application framework |
| **A** | Angular | Frontend framework for building single-page applications |
| **N** | Node.js | JavaScript runtime for server-side development |

---

## Stack Overview

The MEAN stack provides an end-to-end JavaScript solution for building modern web applications:

- **MongoDB** -- Stores data as flexible JSON-like documents, making it easy to pass data between server and client
- **Express.js** -- Handles HTTP requests, routing, and middleware on the server side
- **Angular** -- Provides a component-based frontend framework with TypeScript, two-way data binding, and dependency injection
- **Node.js** -- Runs JavaScript on the server, enabling a unified language across the full stack

---

## Prerequisites

- **Node.js** (v18 or higher) and **npm** installed
- **MongoDB** installed locally or a MongoDB Atlas account
- **Angular CLI** installed globally: `npm install -g @angular/cli`
- Basic understanding of JavaScript and TypeScript
- Familiarity with REST API concepts

---

## How to Use

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd MEAN
   ```

2. Follow the learning materials and build projects that integrate all four technologies.

3. Typical MEAN project setup:
   ```bash
   # Backend
   mkdir server && cd server
   npm init -y
   npm install express mongoose cors

   # Frontend
   ng new client
   cd client
   ng serve
   ```
